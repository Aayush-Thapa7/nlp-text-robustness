# 📊 results/

This directory stores the outputs of experiments: plots, tables, and summary reports.

> **Results are generated by running notebooks or scripts — they are never invented manually.**

---

## What Belongs Here

| Type              | Description                                              | Committed? |
|-------------------|----------------------------------------------------------|------------|
| `figures/`        | PNG/PDF plots (degradation curves, bar charts, etc.)     | ✅ Yes — small files, useful to track visually |
| `tables/`         | CSV/Markdown tables of evaluation metrics per experiment | ✅ Yes — lightweight and human-readable |
| `reports/`        | Written summaries, interim findings, final analysis      | ✅ Yes — Markdown text files |
| Raw model outputs | Large `.pkl`, `.h5`, or `.pt` prediction files           | ❌ No — excluded via `.gitignore` |

---

## Result Integrity Rules

1. **Never edit result files manually.** All results must be produced by running the corresponding notebook or script.
2. **Always record the experiment conditions** (model name, dataset split, random seed, corruption type, intensity level) alongside the metric values.
3. **Do not commit large binary files** (model outputs, HDF5 files, serialized predictions). Save those locally in `data/processed/` (git-ignored) if needed.
4. **Re-running an experiment should reproduce the same numbers** — if it doesn't, document why (e.g., stochastic model, GPU non-determinism).

---

## Generating Results

Results are produced by running the notebooks in order:

```bash
# From the project root, with .venv active:
jupyter nbconvert --to notebook --execute notebooks/03_baseline_experiments.ipynb
```

Or simply open and run the notebooks interactively in Jupyter.
